# Humanitarian Programme Data Analysis

## Project Overview
This project uses PostgreSQL to analyze humanitarian programme data and understand how partner organizations distribute assistance across villages, districts, and regions.

## Objectives
- Analyze beneficiaries reached by each partner.
- Identify the number of villages served by each partner.
- Identify villages served by multiple partners.
- Calculate beneficiary coverage against village population.
- Summarize beneficiary reach by partner and district.

## Tools Used
- PostgreSQL
- DBeaver

## SQL Concepts Applied
CREATE TABLE, INSERT, SELECT, WHERE, CASE WHEN, JOIN, GROUP BY, COUNT, SUM, AVG, DISTINCT, and CREATE TABLE AS SELECT.

## Expected Outcome
The project produces partner and district summary tables to support data-driven decision-making, improve resource allocation, and assess humanitarian programme coverage.
